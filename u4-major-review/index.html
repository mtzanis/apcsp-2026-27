Reminder 1 · Unit 4 Lessons 1 to 4

A variable holds one value. Assignment replaces it.

Work out the right-hand side first, using the values the variables hold right now. Then store the result. The old value is gone.
var a = 10;
var b = 4;
var c = a - b;
a = c;
b = a + b;

Counter pattern

score = score + 1; reads the old value, adds, stores the new one.

Strings and +

"Lab" + "App" is "LabApp". With a string, + joins. No space unless you type one.

MOD

The remainder. 17 MOD 5 is 2. 4 MOD 6 is 4. Even means n MOD 2 = 0.

Create it once

var creates. Put it at the top, outside every onEvent and function, or it starts again each time.

Reminder 2 · Unit 4 Lessons 5 to 8

A chain makes exactly one choice

Conditions are checked from the top. The first true one runs its block, and the rest of the chain is skipped.

AND, OR, NOT

AND: both must be true. OR: at least one. NOT: flips it. In App Lab: &&, ||, !.

Chain or separate ifs?

Three separate if statements are three separate decisions: every condition is checked, and more than one block can run.

Test the boundary

For > 65, try 65 itself. For >= 65, try 64 and 65. Most wrong answers live exactly there.

Reminder 3 · Unit 4 Lessons 9 to 11

Declare it once. Call it wherever you need it.

A declaration runs nothing. A call, the name followed by ( ), jumps into the function, runs its body, and comes back to the line after the call.
var score = 0;
var lives = 3;

onEvent("rightButton", "click", function(){
  score = score + 1;
  updateScreen();
});
onEvent("wrongButton", "click", function(){
  lives = lives - 1;
  updateScreen();
});

function updateScreen(){
  setText("scoreLabel", score);
  setText("livesLabel", lives);
  if (lives == 0){
    setText("msgLabel", "Game over");
  }
}

The updateScreen pattern

Each button changes its data, then calls the one function that shows it. The screen code is written once, and a change is made in one place.

Global and local

A variable created with var at the top is global: everything can read and change it. One created with var inside a function is local: it exists only while that function runs.

What functions are for

Less repeated code, one place to fix, a name that says what the code does. Not speed, and not memory.

Reminder 4 · Unit 7 Lessons 1 and 2

Values go in through parameters. One value comes back through return.

The call becomes the value that was returned. Then the rest of the line carries on.

Parameter and argument

The parameter is the name in the declaration: age. The argument is the value in the call: 8. They are matched by position.

Display is not return

A function that only displays gives nothing back. Storing its result gives undefined. To use a value later, return it.

return ends the function

The moment a return runs, the function is over. Nothing after it in that call is reached.
